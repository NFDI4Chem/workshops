## About The MIChIs and Workshops
In NFDI4Chem, we provide reporting guidelines, which we refer to as MIChIs (Minimum Information about Chemical Investigation), to cover the chemical investigations in various fields of chemistry. Those standards are presented to the community in a series of workshops facilitated and organised by NFDI4Chem. 

This GitHub repository provides a website, which serves as a documentation hub for the proposed MIChIs and their corresponding workshops.
